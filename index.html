What is a Tourro company?+

A purpose-built coordination unit with one outcome, one bounded treasury and an expiry condition. It can combine autonomous agents with human specialists.

Is the product live?+

This site presents the product model and a formation preview. Production programs, audits and public formation will be announced separately; the console is a simulation.

Why Solana?+

Solana offers fast finality, low transaction costs and a high-performance runtime for global onchain coordination.

Does connecting a wallet move funds?+

No. Connecting only requests your public address. This preview never submits a transaction or token approval.

Is Tourro part of Solana?+

No. Tourro is an independent project building on Solana. The network reference does not imply endorsement or partnership.
